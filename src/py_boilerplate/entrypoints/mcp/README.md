# MCP

La superficie MCP usa il Python SDK v2 e il trasporto stdio. Il server espone un solo tool curato, `hello_world`, read-only e idempotente, con descrizione scritta per il modello. Il test di integrazione usa il trasporto in-memory; l'E2E avvia il processo reale.

La documentazione completa è in [`docs/PROJECT.md`](../../../../docs/PROJECT.md) e [`docs/development/TESTING.md`](../../../../docs/development/TESTING.md).
