# Session digest

Un digest di sessione aiuta a riprendere il lavoro senza rileggere una trascrizione. Non è un diario e non contiene segreti.

## Formato

```text
## YYYY-MM-DD — Titolo breve

- Obiettivo:
- Fatto:
- Test eseguiti:
- Decisioni:
- Rischi aperti:
- Prossima azione:
```

## Regole

- Scrivi un digest solo per sessioni con lavoro non banale.
- Cita file, simboli e comandi, non intere conversazioni.
- Rimanda a ADR, PDR o commit invece di duplicarne il contenuto.
- Aggiorna o elimina un digest quando le informazioni diventano obsolete.
- Un digest non sostituisce il report finale del task né la documentazione canonica.
